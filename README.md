# 🕹️ Arcade Java → JS (conversão contínua)

Coleção convertida em lotes para a web: **`arcade/`**.

```bash
npm install   # no-op (zero dependências)
npm start     # http://localhost:3000/arcade/
npm test      # testes das salas já portadas (9/9)
```

- **`arcade/manifest.json`** — 347 apps únicos catalogados (dedup por hash), com categoria
  (Swing-GUI / JOptionPane / Console-Scanner) e status de conversão.
- **1ª sala portada:** `arcade/apps/estatistica/` — Calculadora de Probabilidade
  (port fiel do `Calculadoradeprobabilidade.java`, fórmulas originais mantidas).
- Próximos lotes: as IAs seguem o manifest (GUI → JOptionPane → console), criando
  `arcade/apps/<nome>/` + testes em `test/` (ver PLANO.md seção 4.7 do workspace).
