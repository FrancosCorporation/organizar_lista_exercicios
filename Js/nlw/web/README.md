# Happy — interface web

Aplicação React para encontrar orfanatos em Inhumas. O mapa usa OpenStreetMap e não exige token de serviço.

## Requisitos

- Node.js 22.12 ou superior.
- npm.

## Desenvolvimento

```bash
npm ci
npm start
```

Abra o endereço local informado pelo Vite. O servidor de desenvolvimento escuta apenas em `127.0.0.1`.

## Verificações

```bash
npm run check
npm run build
```

`npm run check` valida os tipos TypeScript. Ainda não há suíte de testes configurada.
